# School Safety System — ProtCo

## 📌 Mga Impormasyon
**Course / Block:** BSIT-3E
**Proyekto Para:**
ProtCo: An AI-Assisted Web-Based Spatial Decision Support System for School Infrastructure Vulnerability Assessment and Disaster Recovery Planning at Cawayan Elementary School
**Framework:** Django (Python)
**Database:** PostgreSQL

## 📄 Deskripsyon
Ang system na ito ay binuo para sa layunin ng disaster safety at school security. Kasama rito ang mga tampok tulad ng incident reporting, infrastructure damage assessment, real-time weather forecast, at object detection gamit ang YOLOv8 para sa safety monitoring.

Bago patakbuhin ang system, siguraduhing naka-install ang mga sumusunod sa iyong computer:

- **Python 3.10+**
- **PostgreSQL 14+**
- **pip** (Python package manager)
